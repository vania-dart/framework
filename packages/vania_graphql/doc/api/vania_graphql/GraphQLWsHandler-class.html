GraphQLWsHandler

GraphQLWsHandler class

Implements the graphql-ws sub-protocol on top of a single upgraded WebSocket.

Wire protocol messages we handle: client → server: connection_init, subscribe, complete, ping, pong server → client: connection_ack, next, complete, error, ping, pong

One GraphQLWsHandler instance handles one WebSocket. It multiplexes any number of subscriptions the client subscribes to, keyed by the per-request id the client picks.
