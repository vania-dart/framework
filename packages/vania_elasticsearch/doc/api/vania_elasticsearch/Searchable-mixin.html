Searchable

Searchable mixin

Marks a Model as searchable via Elasticsearch.

Override searchableAs to change the index and toSearchable to change which attributes are indexed. The default implementations use the model's tableName as the index name and its toJson() for the body.

class Post extends Model with Searchable {
  Post() {
    tableName = 'posts';
  }
}

await post.searchable();                 // index this document
final hits = await Post().search('kids');
